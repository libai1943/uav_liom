1. Keep this folder alongside code/, code_search/, tools/, and results/ in the project root.
2. MATLAB R2021b; CasADi MATLAB distribution 3.6.1 is currently at C:/casadi. Adjust that path in the entry scripts if installed elsewhere. The OSQP Python service/dependencies are the same as in the main release. Ipopt/MUMPS is bundled with this CasADi distribution. No AMPL/HSL archive binaries are needed.
3. In MATLAB: addpath('comparisons_20261031'); FinalExternalSelftest; FinalExternalStudy('final'). Saved attempts are skipped; use a copied result directory to request fresh runs.
4. The delivered comparison is audited by analyze_verified.py. It combines all unchanged proposed/RSC/direct-NLP rows from the formal phase with all corrected ASCO and norm-SCP rows from the verified phase. All ten ASCO and all ten SCP cases were replaced together, before inspecting their rerun outcomes. The original phase and six pilot attempts are retained. It checks source hashes, common inputs, solver routing, saved endpoint/integration checks, and creates the paired table.
5. design.mat fixes the ten case sources. The package includes those sources, each with its saved common reference. Every method is charged that same reference-generation time. This isolates the subsequent planning comparison while retaining the recorded initialization cost.
6. Exact solver statistics and every candidate/check report are saved in per-attempt MAT files. summary.csv provides all attempts; a physically accepted trajectory that exceeds the nominal total budget is marked separately.
7. The inherited implementationVersion in each base configuration identifies the frozen UAV-model version; the actual per-call backend is recorded in result.history.info.backend. External nonlinear comparisons are an isolated extension and do not change the OSQP proposed planner.
8. CPU and wall-clock times are distinct; occasional wall/CPU ratios reflect worker accounting and system scheduling. Data are not timing-normalized to force agreement. The comparison is case-based, with one new paired execution per task, and does not estimate population reliability.

FinalExternalStudy reruns all five final implementations in rotated serial order from the saved ten inputs. The current table records the existing serial-phase measurements; source provenance is explicit in results/external_20261031_audit.json.
SCP follows the norm tangent of Augugliaro et al. (2012), Eq.17, https://www.dynsyslab.org/wp-content/papercite-data/pdf/augugliaro-iros12.pdf. AABB supporting planes and geometric directions at coincident reference points complete the task adaptation. Numeric assembly avoids symbolic QP construction overhead.
ASCO v2 separates its 5s nonlinear-solve CPU cap from the remaining total planning budget; model construction consumes the total budget. All v1 outcomes are retained as implementation diagnostics, not mixed into the final table.
