# Fixed-horizon cooperative UAV trajectory optimization

Research implementation and reproducibility materials for layered feasibility recovery in multi-UAV cooperative flight.

The complete, versioned code, simulation records, manuscript sources, and release archives are being prepared for upload. The revised comparison uses OSQP for quadratic programs and Ipopt/ma57 for nonlinear external baselines.

This repository includes computational planning and software-based rigid-body closed-loop tracking. Release records distinguish accepted trajectories, late accepted trajectories, and unsuccessful attempts.
